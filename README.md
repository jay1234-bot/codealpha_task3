# ✦ PIXORA — Modern Image Gallery

> A modern, responsive and interactive image gallery built with HTML, CSS and Vanilla JavaScript.

PIXORA is a premium-style image gallery created as part of my **CodeAlpha Internship**. The project focuses on responsive UI design, smooth animations, interactive image browsing and clean frontend development.

---

## ✨ Features

- 🖼️ Modern and responsive image gallery
- 🔦 Fullscreen image preview with Lightbox
- ⬅️ Previous & Next image navigation
- 🏷️ Category-based image filtering
- 🎨 Smooth hover effects and transitions
- 📱 Fully responsive design
- ⌨️ Keyboard navigation
- 🌙 Premium dark-themed interface
- ⚡ Lightweight Vanilla JavaScript
- 🖥️ Desktop, tablet and mobile support
- 🚀 Lazy-loaded images
- ♿ Basic accessibility support

---

## 🎨 Categories

PIXORA includes multiple photography categories:

- Nature
- Architecture
- Cars
- Travel
- People
- All

Users can instantly filter images by category without reloading the page.

---

## 🔦 Lightbox

Click any image to open the fullscreen Lightbox.

The Lightbox includes:

- Large image preview
- Previous / Next buttons
- Image counter
- Image title
- Image category
- Close button
- Background click to close
- `ESC` key to close
- `←` / `→` keyboard navigation

---

## 🛠️ Built With

- **HTML5** — Structure
- **CSS3** — Styling, responsive layout and animations
- **Vanilla JavaScript** — Functionality and interactions
- **Google Fonts** — Typography
- **Lucide Icons** — Interface icons

> No frontend framework was used. PIXORA is built entirely with HTML, CSS and Vanilla JavaScript.
